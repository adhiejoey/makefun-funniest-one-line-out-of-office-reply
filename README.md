One out-of-office line with a twist nobody expects: the person is away, but the
auto-reply itself has been promoted to acting manager — and the first thing it
did with its new power was approve its own holiday. It reads like a real away
message, lands on the first read, and skips the beach, the inbox pile-up and
every other away-message cliché.

## How it works

`main.ts` writes the single entry line to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR` (default `/output`).
